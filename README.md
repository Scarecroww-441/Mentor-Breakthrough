# Mentor-Breakthrough
Образовательный симулятор педагогических ситуаций в рамках курсового проекта
Описание игры
«Наставник: Прорыв» — это образовательная визуальная новелла с элементами менеджмента и мини‑играми.
Вы играете роль молодого преподавателя, которому поручили сложную группу.
Ваша задача — повысить успеваемость студентов, поддерживать их настроение и правильно реагировать на возникающие проблемы.

Игра сочетает:

управление временем,
анализ педагогических ситуаций,
выбор методик обучения,
мини‑игры (Тетрис и Дино),
развитие доверия и понимания студентов.

Игровой процесс
Структура игрового дня
Каждая неделя состоит из трёх дней:

Учебный день — работа со студентами, решение проблем.
День развития — посещение кабинетов (завуч, методист, психолог, коллега).
У вас есть 9 единиц выносливости (stamina) на учебный день.
Каждое действие тратит 1 единицу.

Главный экран (Dispatcher)
На экране отображаются:

Время (stamina)
Неделя и день
Средняя успеваемость группы
Проблемы студентов (иконки на карте)

Доступные действия:
Пропустить ход — тратит 1 stamina, проблемы ухудшаются.
Закончить день — завершает учебный день.

Проблемы студентов
На карте появляются значки:
🟢 зелёный — лёгкая проблема
🟡 жёлтый — ухудшение
🔴 красный — критическое состояние
Нажмите на значок, чтобы открыть книгу (Book).
Экран «Книга»
Состоит из трёх колонок:
1. Проблема
название
описание
текущий уровень (цвет)
2. Методика
Выберите один из 12 методов.
Каждый метод показывает:
шанс успеха
описание
доминирующую характеристику
3. Студент
имя
педагогические наблюдения
характеристики
После выбора метода нажмите ПРИМЕНИТЬ.
Применение методики
После применения:
открывается окно результата,
меняются параметры студента (успеваемость, настроение, familiarity),
проблема исчезает при успехе,
тратится 1 stamina,
проблемы других студентов могут ухудшиться.
День развития (Meeting Choice)
Вы можете посетить один из кабинетов:
Кабинет завуча
Даёт +10% к глобальному шансу успеха методов.
Методический кабинет
даёт бонус к случайной методике,
запускает мини‑игру Тетрис,
повышает характеристику структурность.
Психолог
запускает мини‑игру Дино,
улучшает настроение всей группы.
Коллега
даёт временный бонус familiarity одному студенту.
Мини‑игры
Мини‑игра «Студентик» (Dino Game)
Управление:
↑ или SPACE — прыжок
↓ — присесть
ALT — пауза
Цель — продержаться как можно дольше.
Результат влияет на настроение группы.
Мини‑игра «Тетрис»
Управление:
← → — движение
↑ — вращение
↓ — ускорение падения
SPACE — пауза
«Завершить» — выход
Результат влияет на характеристику структурность.
Конец игры
Игра завершается:
Победой, если средняя успеваемость ≥ 70 к концу 4‑й недели.
Поражением, если успеваемость ниже или все студенты отчислены.
Сохранения
Игра автоматически сохраняет:
рекорд Тетриса,
прогресс мини‑игр,
состояние persistent‑данных.
Требования к техническим средствам
ОС: Windows 7 SP1 / Windows 8 / Windows 10 (x64)
Процессор: двухъядерный 2.0 ГГц (Intel Core 2 Duo / AMD Athlon II)
Оперативная память: 4 ГБ
Видеокарта: интегрированная Intel HD Graphics 3000 или аналог
Разрешение экрана: 1366×768
Свободное место: 1.5 ГБ
Дополнительно: установленный DirectX 11, поддержка OpenGL 2.1
Лицензия
Проект учебный, распространяется свободно.
